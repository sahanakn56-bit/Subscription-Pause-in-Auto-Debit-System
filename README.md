Subscription Pause in Auto-Debit System

Project Overview

The Subscription Pause in Auto-Debit System allows users to temporarily pause and resume automatic subscription payments.

Problem Statement

Why isn't subscription pause logic built into auto-debit infrastructure?

Technologies Used

- Frontend: React.js, Vite
- Backend: Python
- Database: PostgreSQL / SQLite
- API: FAST API

Key Features

- User subscription management
- Pause and resume subscriptions
- Automatic debit management
- Database integration

Project Structure

- Backend – Handles application logic and APIs.
- Frontend – Provides the user interface.
- Documentation – Contains project documentation.
- Testing – Contains testing-related files.

Objective

To provide users with better control over recurring payments by allowing them to pause and resume subscriptions when required.
